What are we even doing as an industry? A malicious resource pack containing _fonts_ can remotely execute code on one very specific Minecraft for Windows version. This is both "a nothingburger" and "actually pretty unnerving if you develop an online game". No funky domain, just a [GitHub repository](https://github.com/bikini/minecraft2shell).
