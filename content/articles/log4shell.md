Title: Log4Shell
Date: 2021-12-09
Slug: log4shell
Cves: CVE-2021-44228
Summary: A remote code execution vulnerability in Apache Log4j's message lookup feature.

Log4Shell was a remote code execution vulnerability in Apache Log4j 2. An attacker who could cause a vulnerable application to log a crafted string could trigger a JNDI lookup and load attacker-controlled code. See the [Apache Log4j security advisory](https://logging.apache.org/log4j/2.x/security.html#CVE-2021-44228) and the [CVE record](https://www.cve.org/CVERecord?id=CVE-2021-44228).
