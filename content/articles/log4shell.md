Title: Log4Shell
Date: 2021-12-09
Slug: log4shell
Cves: CVE-2021-44228
Summary: A remote code execution vulnerability in Apache Log4j's message lookup feature.

Log4Shell was a remote code execution vulnerability in Apache Log4j 2, but more importantly, it's where we first see this naming pattern show up. It was so dramatic, so vast in scope that it left its mark on vulnerability disclosures forever more.

These were still early days, though: there's no marketing website for the bug!
