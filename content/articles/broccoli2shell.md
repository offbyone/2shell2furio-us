Title: Broccoli2Shell
Date: 2026-10-23
Slug: broccoli2shell
Cves: CVE-2026-111497
Summary: An out-of-bounds write in Google's Brotli decoder affecting Node.js, Python packages, and other software.

Broccoli2Shell is an out-of-bounds write in Google's Brotli decoder that can be reached through software including Node.js and Python Brotli bindings, potentially leading to memory corruption or remote code execution. See the [Broccoli2Shell disclosure](https://broccoli2shell.com/) and the [CVE record](https://www.cve.org/CVERecord?id=CVE-2026-111497).
