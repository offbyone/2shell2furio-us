Title: PHP2Shell
Date: 2026-10-21
Slug: php2shell
Cves: CVE-2026-109618, CVE-2026-109619
Summary: Two critical remote code execution vulnerabilities affecting supported and historical PHP releases.

PHP2Shell names two PHP remote code execution vulnerabilities affecting PHP versions 5.4 through 8.5. They were patched in coordinated PHP security releases. See the [PHP security release announcement](https://www.php.net/archive/2026.php#2026-10-20-1), [CVE-2026-109618](https://www.cve.org/CVERecord?id=CVE-2026-109618), and [CVE-2026-109619](https://www.cve.org/CVERecord?id=CVE-2026-109619).
